室内最短路径，可能最难识别

多径传播
各路径信号以复数形式叠加。

非视距遮挡
直达路径被阻塞或较弱。

注意： 幅度、相位和延迟仅给出沿一条路径的距离。反射对所有三个都产生偏差，并且稳定的偏差在平均后仍然存在。

上一页介绍用幅度、相位或时延测距，这些特征只有在单路径传播时才与距离呈简单关系。室内存在直达路径和更长的墙面反射路径；接收信号是各路径复数波形的叠加。幅度可能相长或相消，因此移动几厘米或频率略变就可能产生深衰落。合成信号的相位并非直达路径相位，它随频率可能出现弯曲。直达路径最先到达，但随后到达的强反射可能掩盖它。墙壁或人体遮挡直达路径后，更长路径可能占主导，形成持续距离偏差。平均能减小随机噪声，却不保证消除这类偏差。改变频率、天线或位置会改变多径叠加方式，有助于缓解衰落，但不能消除所有观测共有的偏差。教学实验宜只改变一个条件，例如方向或障碍物，比较改变前后的原始测量依据。
