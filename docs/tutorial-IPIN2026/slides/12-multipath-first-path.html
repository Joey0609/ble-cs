Indoors, the shortest path may be the hardest to see

Multipath
Signals add as complex waves.

No line of sight
The direct path is blocked or weak.

Warning: amplitude, phase and delay give the range only along one path. A reflection biases all three, and a stable bias survives averaging.

The previous slide read a range from the signal's amplitude, phase or delay. Each of those follows distance only when the signal takes one path. Indoors it does not: point to the direct path and the longer path reflected off the wall. The receiver sees the sum of every path as complex waves. Amplitude: the copies add or cancel, so the strength fades deeply over a few centimetres of movement or a small change of frequency. Phase: the phase of the sum is not the phase of the direct path, so it can curve with frequency rather than follow a single line. Delay: the direct path arrives first, but a later and stronger reflection can hide it. When the direct path is blocked or weak, by a wall or a body, a longer path dominates and produces a persistent range bias. Averaging helps random noise but does not necessarily correct that bias. Changing the frequency, the antenna or the position changes how the paths add, which helps against fading, but it does not remove a bias every measurement shares. The most useful teaching experiment is to change one condition, such as orientation or an obstacle, and compare the raw evidence before and after.
