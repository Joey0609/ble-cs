Explain the six permitted non-Mode-0 combinations, grouped here into three rows. The app exposes exactly these choices. Mode zero is not selected as the main ranging mode. When a sub-mode exists, the minimum and maximum main-step counts bound the block before each insertion. Actual counts are randomized within the rules. A main/sub sequence can continue across subevent boundaries while a new Mode-0 prefix appears at each subevent. The offline planner selects an illustrative cadence; it cannot predict the controller's exact random decisions. Have the audience read the small sequence aloud and identify what each step contributes.
