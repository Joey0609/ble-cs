名称附加蓝牙地址，不带冒号： CSTagEDE1EB098EEE 是标签 1。

在“配置”视图中，按“打开”浏览文件对话框直接显示的示例并加载配置。在应用之前，先浏览一下生成的时间表：连接时间线、测距过程、事件和子事件、个人步骤和信道序列。将每个组件与加载的设置相关联，并将说明性控制器值与请求的配置区分开。

应用配置，然后按“扫描”以发现对端。检查找到的设备的名称和蓝牙地址。使用适当的表将每个发现的标签或反射端与其分配的 ID 匹配，然后在连接之前选择分配的对端。标签作为 CSTag 进行广播，后跟其地址（不带冒号）。其他反射端宣传为 CSReflector，后跟其地址（不带冒号）。例如，CSTagEDE1EB098EEE 与 ED:E1:EB:09:8E:EE 匹配，即表中的标记 1。扫描结果会持续到达，直到参与者明确连接到其选定的对等方或停止扫描。这些地址来自工坊设备截图。然后运行受控的成对测距实验并检查观测结果。
