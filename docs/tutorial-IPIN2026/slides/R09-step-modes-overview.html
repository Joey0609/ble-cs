Four step modes, four clear purposes

Mode What happens What it contributes
0 Synchronization + frequency measurement Offset calibration
1 Timed CS_SYNC packet exchange RTT
2 Tone exchange on antenna paths PBR
3 CS_SYNC + tones within one step RTT + PBR
Bluetooth Core 6.0 · Vol 6, Part H·Our CS app · source notes

Present the four mode numbers as a map for the following slides. These are modes of individual steps inside a procedure, not four unrelated applications. Mode zero supplies calibration information rather than an independent distance estimate. Mode one is packet timing. Mode two is tone phase. Mode three contains both types of activity. A procedure contains a Mode-0 prefix and ranging steps; supported modes and combinations still have to be checked against controller capabilities.
