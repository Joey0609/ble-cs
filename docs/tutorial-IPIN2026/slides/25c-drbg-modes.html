ModeRandomized choicesPurpose
0 · calibrationMode-0 channel order; CS_SYNC Access Addresses.Synchronize and calibrate on the shared sequence.

Core 6.0 · Vol 6, Part H, §2; §4.3–4.8

This table describes the Core 6.0 mode behavior. Mode 0 uses CS_SYNC with no optional RTT payload. Mode 1 and mode 3 use the configured RTT type: AA-only, sounding sequence or random sequence; do not imply that every RTT packet carries a random payload. The sounding pattern itself is regular, with randomized marker positions and bits. Tone-extension presence is chosen independently for the two transmissions; an absent extension transmission still occupies its time slot. Path permutation is meaningful when more than one path exists. A mode-2 step contains tones, not a CS_SYNC packet. Random phase rotation of every tone is not one of the listed DRBG uses. CSA #3a is for mode 0 and #3b/#3c for other modes. The number of main-mode steps before each sub-mode step is drawn within the agreed minimum and maximum bounds.

Sources: Core 6.0 · Vol 6, Part H, §2; §4.3–4.8.
