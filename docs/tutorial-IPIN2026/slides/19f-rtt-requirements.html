What round-trip timing requires

01 · KNOWN PACKET

A pattern to correlate against

Also assumed: the correlation peak belongs to the first path, which multipath can hide.
Core · Vol 6, Part H, §3.1 (measuring RTT)

The two-interval equation hides four requirements, the counterpart of the phase-based list. First, a known packet: the receiver can only find an arrival time by correlating with a pattern it expects, the access address and, if configured, a sounding or random sequence; the signal bandwidth and the SNR decide how sharp that peak is. Second, both intervals must meet: the reflector reports its own departure minus arrival, so its turnaround does not have to be exact, only measured. Third, the clock rate: the two crystals tick at slightly different rates, mode 0 measures the fractional frequency offset, and the initiator corrects the round trip with it. Fourth, calibration: timestamps are defined at the antenna port, so each device removes its internal transmit and receive delays; any residual is a constant range bias. Underneath: the correlation peak is assumed to be the direct path. Indoors a stronger reflection can dominate, which pulls the estimate long, and where security matters a random sequence makes an early, forged arrival harder. This slide closes round-trip timing; next comes the frequency calibration that both methods depend on.
