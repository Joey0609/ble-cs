Our CS app · source notes

Walk through the actual toolbar sequence. Select the client port, connect, apply the host configuration or synchronize with the client, scan for the intended peer, connect it and start the session. Start remains unavailable until the required configuration and peer state are ready; the tooltip explains the missing step. Stop retains the Bluetooth link for another run, while changing applied configuration may require disconnecting it. In simulator mode the same controls operate the built-in simulated protocol client. The detailed board/build commands are in the repository's Getting Started guide and the appendix, so participants do not need to compile firmware during this introduction.
