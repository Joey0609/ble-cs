Our CS app · source notes

Start with the boards at the station. The nRF54LM20 DK is the client and the CS initiator; it connects to the computer over its native USB CDC ACM port, not the debug UART. The reflector is a separate Bluetooth device with no cable to the app: either the nRF54L15 DK, with one CS antenna, or the nRF54L15 Tag, whose two antennas are switched by an RF switch so that CS can measure more than one antenna path. The boards are preprogrammed; participants only need the desktop app and a USB data cable. Then walk through the actual toolbar sequence. Select the client port, connect, apply the host configuration or synchronize with the client, scan for the intended peer, connect it and start the session. Start remains unavailable until the required configuration and peer state are ready; the tooltip explains the missing step. Stop retains the Bluetooth link for another run, while changing applied configuration may require disconnecting it. In simulator mode the same controls operate the built-in simulated protocol client. The detailed board/build commands are in the repository's Getting Started guide.
