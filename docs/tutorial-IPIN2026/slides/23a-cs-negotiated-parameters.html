测距前双方需要协商哪些参数？

交互阶段共享或选择的信息
能力角色；可选模式3； RTT 类型与精度；同步包物理层模式；天线/路径限制；定时和频率误差支持。
CS配置Config_ID和CS角色；主/子模式；主模式步骤数上下限与重复数；模式 0计数； RTT 类型与同步包物理层模式。
信道和步骤时序信道映射、重复和选择算法#3b/#3c；支持范围内的收发间隔、频率切换和相位测量时长。
测距过程开始天线配置和测距过程表：偏移、子事件、事件、持续时间、重复间隔和计数。
能力决定支持范围，配置确定测量方法，启动参数确定时间安排。
核心 6.0·第 6 卷，B 部分，§2.4.2.43–49； §5.1.24–26

能力测距过程使用LL_CS_CAPABILITIES_REQ/RSP；可以提供或缓存已知的能力。 LL_CS_CONFIG_REQ/RSP 创建或更新配置，由 Config_ID 标识；不受支持的提案可能会被拒绝。实际的步骤时间在配置中进行，并受到对端设备支持的约束。主机 API 公开请求的限制和本地默认值，而控制器则解析播出参数。天线切换时序是能力信息；用于测距过程的天线配置在开始交换时选择。 ACL 间隔、LL 数据长度和 ATT MTU 是单独协商的，在幻灯片 26 中介绍。

来源： 核心 6.0·第 6 卷，B 部分，§2.4.2.43–49； §5.1.24–26.
