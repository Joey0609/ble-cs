Core 6.0 · Vol 6, Part B, §2.4.2.43–49; §5.1.24–26

The capabilities procedure uses LL_CS_CAPABILITIES_REQ/RSP; known capabilities may be supplied or cached. LL_CS_CONFIG_REQ/RSP creates or updates the configuration, identified by Config_ID; an unsupported proposal may be rejected. The actual step timings are carried in the configuration and constrained by peer support. The host API exposes requested limits and local defaults, while the controller resolves on-air parameters. Antenna switch timing is capability information; the antenna configuration used for the procedure is selected in the start exchange. ACL interval, LL data length and ATT MTU are separate negotiations, covered in slide 26.
