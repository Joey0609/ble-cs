Our CS app · source notes

The screenshot is from the actual Results widget with synthetic test packets, not RF measurements. The four plots show amplitude, wrapped phase, unwrapped phase and the IFFT magnitude range profile. Both the slope and IFFT use the same selected path, tone quality filter and phase correction choice. The IFFT places measured complex products on a 1 MHz frequency grid and leaves missing channels empty. Zero padding locates the displayed peak more smoothly but does not improve physical range resolution. A strong peak may include multipath, so compare it with the phase slope, RTT and a known-distance reference before interpreting it as the direct path. The synthetic example lacks a reported compensation value; that overlay coincides with raw data in this screenshot.
