Our CS app · source notes

Label the arithmetic explicitly as an illustrative budget, not a benchmark of this firmware. Four sequential links consuming twenty milliseconds each already require eighty milliseconds, before other overhead; that gives an optimistic ceiling of 12.5 complete sweeps per second. Actual scheduling can be more complex, so measure it. The app visualizes an RAS reflector-data lane and compares its transfer with the next procedure. Connection interval and ATT MTU can matter for carrying results. More antennas, repeated channels or longer tone windows may improve observability but consume airtime. The sample app is principally pairwise; multi-anchor orchestration is a separate integration task.
