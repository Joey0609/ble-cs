Our CS app · source notes

The workshop boards are already programmed. The hosted nRF54LM20 client connects to the desktop application over its native USB CDC ACM host port, not the debug UART. The separate reflector advertises over Bluetooth. With the supplied boards, participants only need the desktop app and a USB data cable. The simulator is a fallback for learning the controls and cannot stand in for a physical ranging result. The main first-session slide gives the exact toolbar sequence after the app walkthrough.
