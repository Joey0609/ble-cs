What happens in an ACL connection event?

The Central opens each event; the Peripheral may answer on the same data channel

Peripheral latency
The Peripheral may skip eligible events.

Supervision timeout
The link is lost if valid packets stop for too long.

Channel Sounding
CS procedures are scheduled from ACL event anchors.

An ACL connection event is a scheduled opportunity for the two Link Layers to exchange data PDUs. The Central starts each event. The Peripheral can respond after the inter-frame spacing, and both sides may continue exchanging packets during that event. The example channels in the figure are illustrative: channel selection can yield the same or a different data channel in the next event. The connection interval is measured between event anchor points. Peripheral latency allows the Peripheral to skip eligible connection events when it has no data to send. The supervision timeout bounds how long the link can go without a valid packet before it is considered lost. Channel Sounding uses the ACL event counter and anchor timing to schedule CS procedures.
