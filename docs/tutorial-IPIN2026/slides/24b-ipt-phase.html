IPT: phase returned in the tone

Ordinary PBR

Each device measures a phase with an opposite local-oscillator offset.

\(\theta_R = \theta_{\mathrm{ch}} + \Delta\theta_{\mathrm{LO}}\)
\(\theta_I = \theta_{\mathrm{ch}} - \Delta\theta_{\mathrm{LO}}\)

The estimator combines both phase correction terms (PCTs):
\(\theta_I + \theta_R = 2\theta_{\mathrm{ch}}\)

IPT enabled

The reflector applies its measured phase to its outgoing carrier.

\(\theta_{I,\mathrm{IPT}} = 2\theta_{\mathrm{ch}}\)
\(\mathrm{PCT}_{R,\mathrm{IPT}} = A_R + j0\)

The initiator already measures the combined phase; the reflector’s PCT carries amplitude.

The same phase slope gives distance. IPT removes the wait for remote phase data; it does not remove measurement noise, multipath or phase ambiguity.
Core 6.3 · Vol 1, Part A, §9.2·Vol 6, Part A, §6.5

The equations use the ideal reciprocal-channel model and a consistent LO-offset convention. In ordinary PBR, multiply the complex PCTs to cancel the opposite LO terms; their phases add. The app computes this complex product, not the conjugate product; with its receive-phase convention the two-way phase is φ₀ − 4πfd/c, falling with frequency, and other conventions flip the sign. With IPT, the reflector compensates its outgoing carrier so the initiator observation already has the two-way phase. The reflector must report Q = 0, and I conveys measured amplitude. The full two-way complex channel amplitude can still require remote amplitude information even though a phase-only slope estimate does not need it. The applied phase contains the reflector’s measurement error; it is not a noiseless coherent mirror. Phase actuation and settling can introduce additional implementation error.
