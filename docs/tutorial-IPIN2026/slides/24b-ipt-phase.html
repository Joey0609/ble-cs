IPT：在回复单音信号中传回相位

普通PBR

每个设备都测量具有相反本地振荡器偏移的相位。

\(\theta_R = \theta_{\mathrm{ch}} + \Delta\theta_{\mathrm{LO}}\)
\(\theta_I = \theta_{\mathrm{ch}} - \Delta\theta_{\mathrm{LO}}\)

该估计器结合了相位校正项 (PCT)：
\(\theta_I + \theta_R = 2\theta_{\mathrm{ch}}\)

启用 IPT

反射端将其测量的相位应用于其测得的值载波。

\(\theta_{I,\mathrm{IPT}} = 2\theta_{\mathrm{ch}}\)
\(\mathrm{PCT}_{R,\mathrm{IPT}} = A_R + j0\)

发起端已经测量了组合相位；反射端的PCT携带 幅度.

距离仍由相位斜率估计。IPT 可省去等待远端相位数据的时间，但测量噪声、多径和距离模糊仍需处理。
核心 6.3 · 第 1 卷，A 部分，§9.2·第 6 卷，A 部分，§6.5

这些方程使用理想的互易信道模型和一致的 LO 偏移约定。在普通PBR中，乘以复数PCT来抵消相反的LO项；它们的相位相加。该应用程序计算此复数乘积，而不是共轭乘积；根据其接收相位约定，双向相位为 φ₀ − 4πfd/c，随频率下降，而其他约定则翻转符号。使用IPT，反射端补偿其传出载波，因此发起端观察已经具有双向相位。反射端必须报告 Q = 0，并且 I 传达测量的幅度。完整的双向复信道幅度仍然需要远程幅度信息，即使仅相位斜率估计不需要它。应用阶段包含反射端的测量误差；它不是无噪声的相干镜。相位驱动和稳定可能会引入额外的实现误差。
