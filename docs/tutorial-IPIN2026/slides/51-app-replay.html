Our CS app · source notes

The Session tab is the chronological record: commands, frames and logs. The Results tab is the analysis of those observations. Add a description before forgetting the physical conditions. The app keeps temporary live history, but participants should explicitly save a session or enable recording for persistence. Stored data include requested configuration where available, controller reports, raw frames and decoded observations. Hostless captures do not invent a host request. Reopen the saved HDF5 file to compare analysis settings without repeating the experiment; optional MATLAB conversion is available in the app. The screenshot shows synthetic simulator events, not RF measurements.
