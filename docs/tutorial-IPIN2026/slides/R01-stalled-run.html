Use as an instructor reference during the hands-on session. Begin with observable state rather than changing several settings simultaneously. A command timeout can close the app transport to avoid confusing a late reply with another command; reconnect to inspect the actual client state. If the UI is unresponsive, preserve any saved capture and reduce live analysis work before diagnosing RF issues. Do not treat a simulator run or successful firmware build as hardware verification.
