区分 FFO 与 FAE

FFO · 相对频偏

单音信号的偏离程度（以 ppm 为单位）

\( \mathrm{FFO}[k] = 10^{6}\,\dfrac{f[k] - f_0[k]\,(1 + 10^{-6}\,\mathrm{FAE}[k])}{f_0[k]\,(1 + 10^{-6}\,\mathrm{FAE}[k])} \)

步骤 k 的单音信号的测量频率 f[k] 相对于它应该在的位置，作为载波的一部分。在每个模式 0 步骤中测量； |FFO| < 50 ppm (ppm)。

符号约定： FFO > 0 表示单音频率偏高：反射端相对于发起端运行得更快。

FAE·频率合成误差

频率合成器偏离标称信道频率多少

频率合成器将晶体参考转换为具有有限分辨率的每个信道频率，因此在信道 k 上实现 f0[k](1 + 10−6·FAE[k])：微小且可重复的合成误差，以百万分之几为单位。

反射端的单音信号携带其 FAE 和晶体偏移 ε: \( f[k] \approx f_0[k]\,(1 + 10^{-6}\,\mathrm{FAE}[k])\,(1 + \varepsilon) \)，因此 \( \mathrm{FFO}[k] \approx 10^{6}\,\varepsilon \): ε 单位为 ppm，已扣除 FAE。
FFO测量ε，它随晶振差异和温度变化，所以它是每个子事件测量的； FAE 是一种无线设备属性，仅在需要时以表格形式检索（参见幻灯片 23b）。
核心·第 6 卷，A 部分，§3.5.1（相对频偏）

FFO 与 FAE 容易混淆。相对频偏 FFO 是观测量：单音测得频率相对其应有频率的偏差，除以载频并用 ppm 表示。模式 0 步骤 k 的定义为：测得 f[k] 减去已用 FAE 修正的标称频率，再除以该修正频率并乘 10⁶。其绝对值必须小于 50 ppm，发起端以 0.01 ppm 的步进上报采用的值。

频率合成误差 FAE 是反射端硬件属性。锁相环或数控振荡器用晶振参考合成各信道频率，但分频比或调频步长有限，使某些信道的实际合成频率产生微小、可重复的偏差。反射端可用表格公布这一特性，共 72 项，每项约在 −4 至 +3.97 ppm。若 No_FAE = 0 且没有已知表，发起端应在测距前读取，并从 FFO 估计中扣除，使合成器误差不被误认作晶振差。若各信道均准确，FAE 为零；对声明 No_FAE = 1 的设备不得发送表请求。

与上一页 ε 的关系是：发起端以自身时钟测量反射端单音，且自身合成误差已补偿；收到频率约为 f₀(1+FAE·10⁻⁶)(1+ε)。代入定义后 FAE 抵消，得到 FFO ≈ 10⁶ε。正值表示反射端晶振偏快。FAE 是频偏中不属于晶振差的部分，所以在把 FFO 当作 ε 使用前必须处理。柱状图仅作示意，不是实测误差表。
