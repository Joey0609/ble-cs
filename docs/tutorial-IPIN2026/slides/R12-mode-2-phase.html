Mode 2: sample phase on each antenna path

Tone slots measure phase. Switching and extension slots also consume time.
Our CS app · source notes

The initiator transmits tones and the reflector measures phase; the roles then reverse. The selected antenna configuration defines the paths, and each path needs a well-defined measurement slot. The planner includes switching periods and an extension slot, including reserved duration when a transmission is absent. The app excludes that extension slot from normal antenna-path measurements. Keep path identity when combining and comparing phase; different paths can have different hardware bias and propagation.
