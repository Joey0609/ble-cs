路径是发射/接收天线对。多条路径提供了针对不良方向或衰落的多样性，但不会自动成为独立的勘测基站。该规范允许多种天线布置，具体取决于实施能力。本地存储库包括一个带有两个切换天线的 nRF54L15 标签反射端；不要假设此 Nordic Tag 具有与 SensWear 板相同的天线布置。在磨损的戒指上，手和身体也会改变射频环境。步骤内的路径顺序通过天线路径排列从一个步骤变为另一个步骤，并且报告携带排列索引，以便主机可以将每个槽映射回其路径。如果映射错误，来自不同路径的相位会混合，斜率拟合会返回一个看似合理但错误的距离，没有任何标记。将路径 ID 保留在数据集中，并根据经验测试方向、外壳和安装效果。
