Antenna diversity creates paths, not extra anchors

Different orientation.
Different fading.
Different path bias.

Compare paths before combining them.

Two antennas on one board still share essentially one anchor location.

A path is a transmit/receive antenna pairing. Multiple paths offer diversity against poor orientation or fading, but do not automatically become independent surveyed anchors. The specification permits several antenna arrangements subject to implementation capability. The local repository includes an nRF54L15 Tag reflector with two switched antennas; do not assume that this Nordic Tag has the same antenna arrangement as a SensWear board. On a worn ring, the hand and body also change the RF environment. The order of the paths inside a step changes from step to step through the antenna path permutation, and the report carries the permutation index so the host can map each slot back to its path. With the wrong mapping, phases from different paths mix and the slope fit returns a plausible but wrong distance, with nothing to flag it. Keep path IDs in the dataset and test orientation, enclosure and mounting effects empirically.
