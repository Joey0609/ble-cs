Core · Vol 6, Part A, §5.3 (antenna switching)

Multiple antennas are the CS answer to fading: each antenna pair sees the multipath sum of the previous slide differently, so each path has its own H[k]. An antenna path is the pairing of one initiator antenna with one reflector antenna, and there can be one to four of them. The configuration picks the arrangement with the antenna configuration index: 1:1, one antenna on one side and up to four on the other, or two on each side, the 2:2 case. The figure shows 1:4. The paths are measured one after another, not at once: every step that contains tones switches antennas and repeats its tone on each path, all on that step's channel. Each path therefore collects its own phase on every channel the procedure visits, and so its own phase slope and its own distance, as on the right. Paths exist only in steps with tones, so they belong to phase-based ranging; a mode-1 packet exchange for round-trip time uses one antenna, and the controller reports which one. Every extra path adds a tone slot and an antenna switch to every tone step, so more paths mean more airtime; the mode 2 slides show where those slots sit. The figure is illustrative, not to scale.
