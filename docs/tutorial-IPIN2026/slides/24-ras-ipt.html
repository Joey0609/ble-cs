Returning the reflector's measurements

ONE ANSWER · RANGING SERVICE (RAS)

A Generic Attribute Profile (GATT) service returns the reflector's results as they arrive or when requested. The initiator matches them to its own steps by ranging counter.

GATT runs over the ACL link, whose anchors also time the CS events. Result traffic gets only the airtime CS leaves: schedule the two together.

FOR PBR · INLINE PHASE CORRECTION TERM TRANSFER (IPT)

The reflector turns its reply tone by the phase it just measured, so the initiator’s own phase is already the two-way phase, 2θch.

A phase-slope range then needs no reflector measurements. RTT still needs the reflector’s ToD − ToA. Optional, Core 6.3.

Bluetooth Ranging Service 1.0·Core 6.3 · Vol 6, Part B, §4.5.18.1·Vol 1, Part A, §9.2

Start with the motivation. Every CS step is two-way, so every observable is split between the two radios. For phase-based ranging, the reflector measures the initiator's tone and the initiator measures the reflector's tone; each phase carries the unknown oscillator offset with opposite sign, and only their combination gives the two-way channel phase. For round-trip timing, the initiator's ToA minus ToD includes the reflector's turnaround, which only the reflector measured. Until both halves reach one ranging entity there is no distance, however well the radio exchange went. In this project the initiator collects both and forwards them to the desktop app.

The Ranging Service is one standard answer. The reflector is normally the RAS Server and the initiator the RAS Client; these GATT roles are independent of Central and Peripheral. RAS carries the reflector controller's subevent results: in real-time mode as notifications or indications while results become available, in on-demand mode stored per procedure and requested through the RAS Control Point. Segments are reassembled and matched to the initiator's own results by ranging counter and step order. This project subscribes to real-time data.

RAS is GATT, so it travels as ATT PDUs over L2CAP in ACL connection events. CS events are offset from the anchors of that same ACL connection: the offset is at least 500 µs and less than one connection interval, and a CS event may extend beyond the interval. One radio does both, so result traffic can use only the ACL airtime that the CS schedule leaves; if a procedure's results have not drained before the next one, results are delayed or lost. Slides 26d and 26e size this.

For phase-based ranging there is a second answer. With Inline PCT Transfer, optional from Core 6.3, the reflector applies the phase it measured on the initiator's tone to its own outgoing carrier. The oscillator term then cancels in the air, and the initiator's measured phase is already twice the channel phase. A phase-slope distance needs no reflector measurements; the reflector's PCT keeps only its amplitude, with Q equal to zero. IPT does nothing for RTT, so a mode-1 or mode-3 timing estimate still needs the reflector's data.
