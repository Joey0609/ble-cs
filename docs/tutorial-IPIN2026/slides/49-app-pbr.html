The screenshot is from the actual PyQt application using its built-in simulator. Its points are synthetic and must not be used as hardware evidence. Orient the audience to the per-channel views and correction overlays. Change only one analysis choice at a time. A straight-looking phase curve is useful evidence of model consistency, but not proof of absolute accuracy. The correction sign is an experimental convention to verify, not a cosmetic preference.
