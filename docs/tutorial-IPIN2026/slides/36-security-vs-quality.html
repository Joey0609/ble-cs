Bluetooth Core 6.0 · Vol 6, Part H·Bluetooth SIG · technical overview

Explain security at a conceptual level rather than presenting this prototype as a secure-access product. Bluetooth CS includes mechanisms intended to reduce opportunities for range manipulation: protected setup, cryptographic randomization and packet/tone checks. RTT and PBR can supply complementary evidence. The exact protection depends on the chosen security level, supported features and how the application consumes indicators. NLOS bias is a propagation problem, not necessarily an attack. Likewise, an attacker can target a clean-looking estimate. Our educational app should be used to inspect observations and validity, not to certify access-control behavior.
