请大家现在开始安装，让下载在讲解期间后台完成，实践时再打开应用。要求 Python 3.10 或更新版本。Windows 的 Python 启动器通常为 py，安装命令是 py -m pip install ble-channel-sounding。建议使用 pipx 或新的虚拟环境，避免影响其他软件包。安装依赖包括 PyQt6、pyqtgraph、NumPy、SciPy 和 h5py；会议无线网络下载量可能较大，可通过 U 盘或本地镜像提供 wheel 安装包。ble-channel-sounding --simulate 可在不连接开发板时，以合成数据运行完整应用。首次测距会话前再检查一次安装结果。
