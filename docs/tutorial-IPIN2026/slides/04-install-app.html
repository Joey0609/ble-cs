ble-channel-sounding · PyPI

Ask everyone to start the install now and let it run while we talk; we open the app in the hands-on. It needs Python 3.10 or later. On Windows the launcher is py, so the command is py -m pip install ble-channel-sounding. pipx or a fresh virtual environment keeps it apart from other packages. The install pulls PyQt6, pyqtgraph, NumPy, SciPy and h5py, which is a large download on conference Wi-Fi; offer the wheels on a USB stick or a local mirror. ble-channel-sounding --simulate opens the full app on synthetic data, with no DK attached. We check the install again just before the first session.
