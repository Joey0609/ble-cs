Both peers derive the steps locally from the configuration and shared random generator; no per-step timetable is transmitted.
Core 6.0 · Vol 6, Part B, §5.1.26

For a Central-originated start the sequence is request, response, indication. For a Peripheral-originated start the Central can answer with the final indication. A rejection is also possible. The connEventCount and offset establish a common starting instant; the CS event and procedure intervals use ACL connection intervals, while subevent interval uses 625 microsecond units. Configuration parameters are not all renegotiated at this stage. Normal ACL activity continues subject to scheduling; control and result traffic therefore require airtime alongside CS. A procedure-start completion reports the values actually selected.
