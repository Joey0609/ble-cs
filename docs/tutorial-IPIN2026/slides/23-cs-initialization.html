CS 测距过程的初始化

ACL 链路承载初始化交互；然后控制器执行商定的 CS 计划。

  1. 能力查找共享角色、模式、无线设备选项、天线限制和支持的步骤时序。
  2. 反射端校准使用零频率合成误差 (FAE)、已知表，或在需要时检索该表。
  3. 配置商定配置标识符（Config_ID）、测量模式、顺序规则、信道和步骤时序。
  4. CS 安全初始化通过加密数据链路交换种子材料并初始化共享随机生成器。
  5. 测距过程开始同意调度；中心设备发送最终的启动参数。
之前第一个步骤：配置和FAE已知，CS安全准备好，启动时序商定。
核心 6.0 · 第 6 卷，B 部分，§5.1.23–29

这是依赖关系概述，而不是每个设置操作的强制总排序。配置前必须了解能力； CS Security Start 需要加密的 ACL。发起端在CS启动之前需要反射端FAE信息。设置交换不需要在每个测距过程之前重复：可以重复使用可接受的配置和已知功能，并且重复的测距过程推进 DRBG 状态。 中心设备/外围设备为ACL角色； 发起端/反射端根据 CS 配置进行选择。任一设备都可以请求 CS 启动；中心设备提供最终指示。读取控制器完成事件，而不是将成功的主机命令提交视为已完成的协商。

来源： 核心 6.0 · 第 6 卷，B 部分，§5.1.23–29.
