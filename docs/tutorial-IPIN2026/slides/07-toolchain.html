Toolchain

Firmware (nRF54L15 / nRF54LM20)

  • cs_client – USB-hosted CS client
  • cs_hostless_initiator / cs_hostless_reflector
  • cs_reflector_tag – Tag with two switched antennas
  • Shared libraries in common/libs/

PC software (Python, PyQt6)

  • ble-channel-sounding-planner – build and check a CS configuration, export to C
  • ble-channel-sounding – configure, connect, visualize PBR/RTT step data
  • Session recording and replay
