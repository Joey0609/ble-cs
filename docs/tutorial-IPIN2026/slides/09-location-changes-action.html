03 · 理解运动

随时间变化的运动

经过哪条路径？发生了什么区域切换？哪里的定位置信度下降？

先明确定位要支持的决策，再确定精度、延迟与覆盖范围。

用具体场景引入：寻找共享实验设备、机器人与人员会合，或参与者沿室内路线行走。建筑中的传播环境与开阔室外不同。这三个例子说明，轨迹跟踪是一项工程需求，而不只是好看的可视化。找设备可能只需房间级位置；空间交互中，延迟和结果一致性可能更重要。轨迹可支持路线与停留分析，但采集人员位置数据应有明确目的并获得同意。请听众说出自己应用中，什么误差或延迟会改变决策，从而使后续空口时间、滤波和几何布局的权衡更具体。
