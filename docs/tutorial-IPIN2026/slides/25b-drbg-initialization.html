Core 6.0 · Vol 6, Part B, §5.1.23·Vol 6, Part E, §3.1.5

The Central initiates the CS Security Start procedure; these are ACL roles, not CS roles. Both devices contribute fresh random initialization-vector and instantiation-nonce parts. The personalization vector contributes additional input but is not required to be random or treated as critical entropy. Concatenation is shown in specification notation, not packet byte order. h9 instantiates K_DRBG and V_DRBG. This is dedicated CS security material exchanged under ACL encryption, not simply the ACL session key renamed. On restart, outstanding CS procedures and repeats must finish before the security exchange. Normal repeated ranging does not require a new security exchange every time.
