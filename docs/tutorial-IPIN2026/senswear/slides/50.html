Appendix · the phase model in one place

Use only for a derivation question. The alias interval refers to ideal uniform frequency spacing and the two-way phase model, not the guaranteed measurement range. Irregular channel gaps, wrapped phase, noise and multipath complicate estimation. The application is intentionally simple and provides intermediate plots to expose these limits. Frequency in the slope equation must be in hertz, phase in radians and c in metres per second.
