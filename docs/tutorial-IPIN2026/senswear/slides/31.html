Channels: coverage and coexistence

The CS channel arrangement differs from the ordinary BLE data-channel grid. Within 2402–2480 MHz, seven reserved indices leave 72 permitted channels. The application can edit the channel map and overlays reference Wi-Fi bands for context. Its example random generator is deliberately not the CS security DRBG; the actual on-air sequence cannot be inferred from the offline example seed. Losing channels can reduce frequency coverage and complicate slope fitting. For ideal uniformly spaced 1 MHz samples, the nominal two-way phase ambiguity interval is c divided by two delta-f, about 150 m; this is not an operating-range guarantee and gaps can make unwrapping harder.
