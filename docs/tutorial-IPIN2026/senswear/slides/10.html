Bluetooth 6.0 adds a ranging primitive

Position Channel Sounding within Bluetooth LE. It was introduced in Core 6.0. RSSI is a received-power measurement, not a time of flight. Direction Finding is a separate angle technique; do not equate its antenna array processing with Channel Sounding antenna paths. CS adds an interoperable way to exchange and report observations for ranging. A Bluetooth product label alone is insufficient: check the supported features and the firmware implementation on each side. The app also exposes newer options; the main lesson deliberately uses the Bluetooth 6.0 baseline with Inline PCT Transfer disabled.
