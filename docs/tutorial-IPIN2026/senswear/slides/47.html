The lab question: what changes a range?

Set up the second part as an experiment rather than a race to produce the prettiest track. Teams first collect a static known-distance baseline with a reproducible configuration and a consistent antenna reference point. Next, vary orientation or insert an obstacle while holding distance fixed. Finally, change an allowed schedule setting and assess the tradeoff between usable observations and update rate. Record enough context to explain differences. Use separate calibration and evaluation runs for later multilateration. If RF hardware fails, use the simulator for workflow training and a supplied real recording only if one is available; do not label synthetic data as a real fallback measurement set.
