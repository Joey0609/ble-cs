Mode 0: establish the frequency reference

Use the exchange diagram to show the initiator packet, reflector response and frequency-measurement tone. Fractional Frequency Offset describes the frequency difference relevant to the exchange. Fractional Frequency Offset Actuation Error characterizes how accurately a radio realizes an intended frequency; its table is a distinct calibration input. Do not call Mode 0 a measurement of the floor distance. In the app, the Mode 0 / FFO tab plots measured offsets and reported compensation over time. The conceptual diagram deliberately omits guard and ramp durations; the individual-step planner provides the detailed timing view.
