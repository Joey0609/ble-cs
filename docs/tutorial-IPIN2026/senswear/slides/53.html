Appendix · later Bluetooth features stay explicit

This slide avoids mixing specification versions. The application help references Core 6.3, while some planner details cite Core 6.1. Its IPT option changes reflector tone behavior and switching timing. In that mode, the initiator can receive a two-way phase contribution through the modified exchange, and the app has specialized validation and initiator-only analysis behavior. These are not assumed in the Bluetooth 6.0 baseline derivation. Consult the app's IPT technical note and the relevant current standard before enabling it.
