Appendix · documented hardware routes

Keep the nRF54LM20 DK, nRF54L15 DK, Nordic nRF54L15 Tag and SensWear platform distinct. The Tag's two-antenna RF switch is a documented board-specific feature. RTT in the debug/logging column means SEGGER Real Time Transfer, not round-trip-time ranging. The exact wearable build, power arrangement and peer set should be smoke-tested before the workshop. The repository does not lock an SDK west manifest, so match the documented SDK and toolchain across builds.
