Indoors, the shortest path may be the hardest to see

Point to the direct path and a longer reflected path. The receiver sees a superposition of complex contributions, so phase can curve with frequency rather than follow a single line. If the direct path is suppressed, a dominant longer path can produce a persistent range bias. Averaging helps random noise but does not necessarily correct that bias. Other practical contributors include oscillator residuals, antenna delays, body shadowing and bad report pairing. The most useful teaching experiment is to change one condition—such as orientation or an obstacle—and compare the raw evidence before and after.
