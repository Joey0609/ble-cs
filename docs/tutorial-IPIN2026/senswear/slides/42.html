Our app connects theory to the experiment

Name the application: ble-channel-sounding, the Python/PyQt6 desktop host in the supplied ble-cs repository. Its purpose is to connect the theory to a visible experiment with configuration, controller feedback, raw data and replay. In the documented hosted setup, a native-USB nRF54LM20 DK runs cs_client and connects to a reflector; nRF54L15 DK and Tag reflector options are documented. That distinction prevents accidental claims about a USB interface on the nRF54L15 wearable. Radio Test is visible but disabled in this deployment. The simulator exercises the workflow without proving RF accuracy.
