Read what the controller actually accepted

Before diagnosing a surprising graph, confirm the experiment that actually ran. The Controller tab reports capabilities, connection parameters, completed configuration and enabled procedure parameters alongside requests. Some settings are negotiated or controller-selected; the accepted result can differ from the values one expected. The Estimates view then compares the available RTT and PBR summaries. This screenshot is a simulator session. During the live lab, ask participants to name one requested setting and find its reported counterpart.
