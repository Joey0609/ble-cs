The useful tone is only part of the airtime

Use the actual application screenshot as a preview of the detailed timing view. Zoom with the live app if the audience wants individual numbers. T_PM is the phase-measurement period, T_SW an antenna switching period, T_RD ramp-down, T_GD a guard, and T_IP1 or T_IP2 an interlude according to the mode. Frequency-change time is represented between steps in the event view. Longer phase measurement or more antenna paths expands the complete exchange, not merely the visually highlighted tone. The screenshot is an offline plan with explicit example assumptions and is not a captured over-the-air waveform.
